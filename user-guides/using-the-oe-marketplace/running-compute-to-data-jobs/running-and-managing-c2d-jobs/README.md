# Running and managing C2D jobs

Ocean Marketplace provides a wizard to make it easier to run C2D jobs and collect results. You can start a C2D job using either a dataset or an algorithm of type _"compute"_.&#x20;

In the Ocean Marketplace, you can:

* [Run a C2D starting from a dataset](run-a-c2d-starting-from-a-dataset.md)
* [Run a C2D job starting from an algorithm](run-a-c2d-job-using-an-algorithm.md)
* [Manage your escrow account](manage-the-escrow-account.md)
* [See all the C2D jobs you've executed](c2d-jobs-history.md)
