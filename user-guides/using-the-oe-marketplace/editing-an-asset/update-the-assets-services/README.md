# Update the asset's services

To update the asset's services, perform the following:

1\. From the Edit page, select the option "**Edit Service**". The existing services are listed, along with a button to add a new service.

<figure><img src="../../../../.gitbook/assets/image (51).png" alt=""><figcaption></figcaption></figure>



From this screen, you can perform the following:

* [Update an existing service](update-an-existing-service.md)
* [Create a new service](create-a-new-service.md)
